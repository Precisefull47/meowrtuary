# Meowrtuary v1 Preview (1.4.2)

macOS Apple Silicon CLI with artifact acquisition and analysis for supported Ollama,
LM Studio and llama.cpp artifacts. Includes report export, integrity verification,
case comparison, packaging, synthetic validation, and experimental deleted-record
recovery. Minimal cat-branded terminal menu with reduced-motion support.

Validated on the development Mac: 263 unit tests, fresh archive checksums and file
manifest verification, install paths with spaces, runtime diagnostics, synthetic
forensic validation, and a local Homebrew install/test/reinstall/uninstall cycle.

Not independently validated on another Mac. Not Developer ID signed or notarized.
No promise of complete conversation recovery; unsupported formats and permissions
can limit findings. MIT original code; bundled dependencies keep their licenses.
